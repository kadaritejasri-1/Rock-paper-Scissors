# Rock Paper Scissors

A simple Rock Paper Scissors game made using HTML, CSS, and JavaScript.

## Features

- Play against the computer
- Random computer choice
- Shows the winner
- Keeps score
- Reset button

## Technologies

- HTML
- CSS
- JavaScript

## How to Play

Open `index.html` in your browser and choose Rock, Paper, or Scissors.

The computer will make a random choice and the game will show the result.
